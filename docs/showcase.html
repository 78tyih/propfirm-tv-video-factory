04 · FAQ

常见问题 · 四问速览FAQ · The four questions

Q.1解决什么问题？What problem does it solve?＋
系列金融短视频每集都从零搭：风格漂移、素材乱放、配置散落。工厂把骨架、设计系统、素材隔离、注册机制全部固化——新集只填内容。Series videos drift: style inconsistency, scattered assets, loose configs. The factory locks skeleton, design system, asset isolation and registration — new episodes only fill content.
Q.2什么场景用？得到什么结果？Scenario and outcome?＋
PropFirm.TV 自营交易考核内容的系列化生产：选题 → 七步 → 1080p 成片（数字人口播 + 背景素材 + 字幕）。EP01（9 个 Shot）已跑通全流程。Serialized propfirm content: topic → seven steps → 1080p render (avatar + backgrounds + subtitles). EP01 (9 shots) ran the full pipeline.
Q.3内部是什么结构？How is it structured?＋
src/shared/（theme.ts 设计令牌 + types.ts Schema + AvatarCircle/Subtitles 参数化组件）+ src/episodes/（注册表 + EP01/config-shots-script）+ scripts/create-episode.mjs 脚手架。Root.tsx 动态注册所有 Episode。src/shared/ (tokens + schema + parameterized components) + src/episodes/ (registry + EP01) + scaffolder CLI. Root.tsx registers episodes dynamically.
Q.4能复用什么？What can you reuse?＋
① Episode 工厂模式（脚手架 + 注册表 + config 数据驱动）适用于任何 Remotion 系列；② Calm Fintech Editorial 色板与三级字体层级；③ 「只留四类动效」的克制语法；④ 参数化数字人 + 字幕组件。The episode factory pattern, the calm fintech tokens and type tiers, the four-motion-only grammar, and parameterized avatar/subtitle components.
